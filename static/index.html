Before you convert

  • Build on the target device. A TensorRT engine only runs on the GPU and TensorRT version that built it.
  • Max performance mode. Run sudo nvpmodel -m 0 && sudo jetson_clocks for stable timings.
  • Expect a few minutes per engine on Orin Nano. One job runs at a time; others wait in the queue.
  • Compare fairly. Convert YOLOv8 and YOLO11 at the same image size.
